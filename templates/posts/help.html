Puesta en marcha paso a paso

  1. 1
    Crea el bot y obtén el token

    Habla con @BotFather, ejecuta /newbot, elige nombre y usuario. Copia el token y pégalo en Configuración → Token del bot.

  2. 2
    Agrega el bot al canal

    En Telegram: tu canal → Administradores → Agregar administrador → busca el bot → activa «Publicar mensajes». Guarda.

  3. 3
    Registra el canal en el panel

    Entra a Canales y agrega @usuario_del_canal o su ID numérico. Usa el botón de verificar para confirmar el acceso.

    Si el canal es privado, publica cualquier mensaje en él y usa Detectar canal. Para encontrar el ID también sirve {{ chat_ids_command }} desde consola.

  4. 4
    Enciende el programador

    Con el entorno virtual activo, ejecuta en otra terminal:

    {{ scheduler_command }}

    Debe mostrar «Programador en línea» en el panel. Si lo cierras, las publicaciones se quedan en cola.

Formatos y límites

  • Texto: hasta 4096 caracteres. Puedes usar HTML o MarkdownV2.
  • Imagen: JPG, PNG o WEBP de hasta 10 MB. El texto se envía como caption (máximo 1024 caracteres).
  • Sticker: WEBP estático, TGS animado o WEBM de video, hasta 512 KB. No admite texto.
  • Enlaces: puedes ocultar la tarjeta de vista previa en publicaciones de texto.

Ejemplos de formato HTML

<b>Título en negrita</b>
<i>Texto en cursiva</i>
<a href="https://ejemplo.com">Visita el sitio</a>

<b>Oferta del día</b>
Descuento exclusivo para suscriptores.

Si usas MarkdownV2, recuerda escapar caracteres como _ * [ ] ( ) ~ ` > # + - = | { } . ! con una barra invertida.

Comandos útiles

Ejecútalos desde la carpeta del proyecto con el entorno virtual activo:

python manage.py runserver
python manage.py scheduler
python manage.py scheduler --once
python manage.py get_chat_ids
python manage.py createsuperuser

--once envía lo pendiente una sola vez y termina. Útil para probar.

Problemas frecuentes

  • «chat not found»: revisa el chat ID y que el bot siga en el canal como administrador.
  • «not enough rights»: activa el permiso «Publicar mensajes» al bot.
  • No se envía nada: el programador debe estar corriendo; mira el estado en la cabecera.
  • Un envío falló: el error aparece en la fila de la publicación. Corrige y usa «Reintentar ahora».
